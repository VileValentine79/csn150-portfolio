## My Cloned Repositories (AI & Security)
Here are three open-source repositories I explored and cloned for this assignment:

1. **[rzeldent/esp32cam-rtsp](https://github.com/rzeldent/esp32cam-rtsp)**
   * *Why I chose it:* It turns an inexpensive ESP32-CAM microcontroller into a fully functional RTSP security streaming camera server, blending hardware IoT with video surveillance.

2. **[ollama/ollama](https://github.com/ollama/ollama)**
   * *Why I chose it:* It allows developers to run powerful Large Language Models (AI) locally and securely on their own machine, which is great for privacy-first AI engineering.

3. **[sqlmapproject/sqlmap](https://github.com/sqlmapproject/sqlmap)**
   * *Why I chose it:* It is an iconic penetration testing tool that automates the detection and exploitation of SQL injection vulnerabilities in web applications.
